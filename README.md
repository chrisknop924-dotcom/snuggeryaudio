# Snuggery website

The public web pages for Snuggery, served by GitHub Pages. This repo holds
ONLY these pages; the app's code lives in a separate private repository.

- `privacy.html` — the privacy policy the Play Store listing links to.
- `index.html` — a one-paragraph front page.

The canonical copy of `privacy.html` is `website/privacy.html` in the app's
repo; copy it here when it changes.
